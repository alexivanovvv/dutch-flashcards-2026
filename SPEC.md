# Dutch Learning Flashcards — Spec

## Что это

Личный инструмент для изучения нидерландского языка. Флэш-карточки с иллюстрациями, извлечёнными из учебного PDF-пособия. Запускается локально как HTML-файл, без сервера и зависимостей.

---

## Структура файлов

```
DUTCH - LEARNING/
├── flashcards.html            # главное приложение (один файл)
├── Dutch words.md             # словарь в Markdown-таблице
├── Dutch_vocab_outline_A4_landscape (1).pdf   # исходный PDF с иллюстрациями
├── extract_cards.py           # скрипт извлечения изображений из PDF
├── SPEC.md                    # этот файл
├── card_images/               # первая версия вырезанных PNG (167 штук)
├── card_images_dark/          # тёмные версии PNG
└── card_images_updated/       # финальные PNG (используются в приложении)
```

## Скрипт extract_cards.py

Вырезает PNG-иллюстрации из PDF.

**Зависимости:** `PyMuPDF` (fitz), `Pillow`

**Как работает:**
1. Открывает PDF через `fitz.open()`
2. Для каждой страницы извлекает embedded растровое изображение (`page.get_images()`)
3. Раскладывает страницу на секции по жёстко заданным координатам (y_start, y_cut, x_start, x_end) — по одному набору на каждую группу ячеек
4. Вырезает каждую ячейку через `img.crop()` с небольшими внутренними отступами (MX=5, MY=5)
5. Сохраняет PNG в `card_images/` с именем файла = нидерландское слово (например, `emmer.png`)

**Почему жёстко заданные координаты:** PDF image-only без текстового слоя, автодетектировать разделители не получилось — пришлось вручную подобрать пиксельные границы для каждой строки на каждой странице.

Структура SECTIONS:
```python
(page_num, row_bounds, col_bounds, [word_names])
```

## Приложение flashcards.html

Один HTML-файл (~660 строк), без внешних зависимостей. Открывается двойным кликом в браузере.

### Данные карточек

JavaScript-массив `allCards`. Каждый объект:

```js
{
  file: 'emmer',           // имя PNG без расширения
  article: 'de',           // артикль (de / het / '' для глаголов)
  word: 'emmer',           // слово на нидерландском
  en: 'bucket',            // перевод на английский
  ex: 'De emmer is vol.', // пример предложения на нидерландском
  cat: 'Huishouden'        // категория
}
```

Изображения загружаются из `card_images_updated/{file}.png`.

### Интерфейс

**Лицо карточки:** иллюстрация из PDF + подсказка "tik om te draaien"

**Оборот карточки:** нидерландское слово с артиклем (крупно), разделитель, английский перевод, пример предложения на нидерландском (курсив)

**Навигация:**
- Кнопки ← → по бокам карточки
- Клавиатура: `←` `→` `↑` `↓` — переключение; `Пробел` / `Enter` — перевернуть; `S` — перемешать

**Фильтр по категориям:** горизонтальная полоса таблеток `Alle (167)`, `Huishouden (27)`, … При выборе категории колода перемешивается заново.

**Прогресс:** `1 / 167` + прогрессбар

**Shuffle:** кнопка перемешивает текущую колоду

### Аудио (Web Speech API)

- При перевороте карточки произносит артикль + слово на нидерландском
- Язык: `nl-NL` / `nl-BE`
- Предпочтительные голоса на macOS: Ellen (nl-BE, женский) → Xander (nl-NL, мужской)
- Скорость: 0.85x
- Включается/выключается кнопкой с иконкой динамика
- Состояние сохраняется в `localStorage`

### Тёмная/светлая тема

- Переключается кнопкой луна/солнце
- Состояние сохраняется в `localStorage`
- Полная поддержка: карточки, фон, кнопки категорий, прогрессбар

### Анимация

CSS 3D flip: `transform: rotateY(180deg)`, `perspective: 1200px`, `transition: 0.55s cubic-bezier(0.45, 0, 0.15, 1)`. При навигации во время открытого оборота — карточка сначала закрывается (560ms), затем переходит к следующей.

## Ограничения

- Работает только локально (изображения — локальные файлы, не base64)
- Нет прогресса обучения (не помнит, что уже знаешь)
- Только английский перевод, нет русского
- Только тематическая лексика A1–A2, нет грамматики

## Бэклог фич

### Высокий приоритет

1. **Режим "знаю / не знаю"** — после просмотра оборота две кнопки: ✓ Знаю / ✗ Не знаю. Карточки с "не знаю" повторяются чаще. Счётчик прогресса сессии.

2. **Перевод на русский** — добавить поле `ru` в данные карточек (сейчас только `en`). Переключатель EN / RU в шапке.

3. **Deploy онлайн** — заинлайнить все изображения как base64 или собрать в один bundle для публикации без сервера (GitHub Pages, Netlify Drop).

4. **Мобильная оптимизация** — карточка сейчас фиксированная ширина 520px, не адаптируется на телефоне. Нужен responsive layout.

### Средний приоритет

5. **Режим Quiz** — показать оборот (слово), угадать картинку из 4 вариантов. Или наоборот: показать картинку, выбрать слово из 4.

6. **Spaced repetition (SRS)** — простой SM-2 алгоритм вместо случайного порядка. Хранить прогресс в localStorage.

7. **Артикль как отдельный quiz** — карточка показывает слово без артикля, нужно выбрать de / het. Особенно полезно для нидерландского.

8. **Озвучивание примера** — кнопка "▶" рядом с примером предложения, чтобы прослушать произношение фразы целиком.

9. **Поиск** — поле для поиска по нидерландскому слову или английскому переводу.

### Низкий приоритет

10. **Новые категории** — числа, цвета, еда, транспорт, дни недели, время.

11. **Режим "только глаголы"** — карточки с пустым article (werkwoorden), отдельный фильтр.

12. **Печать карточек** — CSS `@media print` для распечатки карточек 2×3 на A4.

13. **PWA** — service worker + manifest для установки на телефон и офлайн-использования.

14. **Статистика** — сколько слов изучено, процент правильных ответов по категориям.
